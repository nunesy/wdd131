📚 Referências e Tecnologias do Projeto

Documentação oficial e padrões de terceiros utilizados no desenvolvimento da aplicação:

  • MDN Web Docs (Mozilla): Utilizado como base de consulta para manipulação avançada de Datas (Date()), manipulação do DOM e métodos de Array (filter, map).
  • LocalStorage API: Padrão nativo do HTML5 para persistência local de dados no navegador do usuário.
  • Tipografia e Ícones: Utilização de fontes padrão do sistema (Verdana e Arial) combinadas com Emojis nativos para máxima performance e leveza no carregamento.
  • Design System: Paleta de cores inspirada em interfaces modernas de produtividade, estruturada via Variáveis CSS (:root) com suporte completo a Modo Escuro (Dark Mode).
